# 02. 프로젝트 데이터 구성

## 1. 데이터 개요

본 프로젝트의 데이터는 **샤프트 측정부 ROI 자동 검출을 위한 YOLO 학습 데이터**와 **외경 정밀측정 성능을 평가하기 위한 측정·Calibration·Validation 데이터**로 구분하여 구성하였다.

프로젝트 초기에는 제한된 수의 샤프트 원본 이미지를 이용하여 YOLO와 OpenCV 기반 측정 가능성을 검토하였으며, 이후 반복 촬영과 3차 현장 촬영을 통해 데이터 범위를 확대하였다.

데이터의 주요 목적은 다음과 같다.

- YOLO 모델 학습을 통한 측정부 ROI 자동 검출
- OpenCV 기반 상·하 Edge 검출
- 31-point 외경 측정
- Pixel-to-mm Calibration
- 독립 Validation
- 반복 측정 안정성 평가
- 재장착 및 촬영조건 영향 분석
- Pin Gauge를 이용한 촬영계 안정성 검토
- 표면거칠기와 광학 Edge 산포 관계 검토

## 3. 01_Drawing

샤프트 외경 측정 대상 부위와 도면 기준을 관리한다.

### 측정 대상

- 자동차 조향장치용 샤프트
- 기준 외경: **Ø20.020 mm**
- 공차: **±0.010 mm**
- 허용 범위: **20.010 ~ 20.030 mm**

도면 정보는 영상 측정 결과의 OK/NG 판정 기준으로 사용한다.

---

## 4. 02_Reference_Measurements

영상 기반 측정값과 비교하기 위한 실제 기준 측정값을 관리한다.

주요 내용은 다음과 같다.

- 시편별 실측 외경값
- Calibration 기준 치수
- Validation 기준 치수
- 표면거칠기 측정값
- 필요 시 Pin Gauge 기준값

대표 시편의 기준값은 영상 측정값과 실제 외경 간 관계를 평가하는 데 사용하였다.

---

## 5. 03_Raw_Images

실제 샤프트 촬영 원본 이미지를 관리한다.

### 초기 데이터

프로젝트 초기에는 소수의 샤프트 원본 이미지를 이용하여 다음 기능을 검토하였다.

- OpenCV 기반 Edge 검출
- 측정부 ROI 설정
- YOLO 적용 가능성
- 외경 Pixel 측정

### 반복 촬영 데이터

이후 Calibration 및 Validation을 위해 동일 시편을 반복 촬영하여 Pixel 측정값의 안정성을 확인하였다.

### 3차 촬영 데이터

최종 파일럿 촬영에서는 다음 시편을 대상으로 반복 촬영하였다.

- NO1 ~ NO10
- NG1
- NG2
- 각 시편 10회 반복 촬영

총 촬영 데이터는 **120장**으로 구성하였다.

3차 촬영 데이터는 다음 분석에 활용하였다.

- 반복 측정 안정성
- Edge 선택 안정성
- Calibration / Validation
- Pin Gauge 변화
- 재장착 영향
- 표면거칠기 영향 검토
- 이상 촬영 이미지 선별

단, 최신 정밀 ROI 분석에서는 해상도가 다른 NO1을 제외하고 NO2~NO10, NG1, NG2의 11개 시편을 사용하였다.

## 6. 04_YOLO_Dataset

샤프트 영상에서 **정밀 외경 측정을 수행할 ROI를 자동 검출하기 위한 YOLO 학습 데이터셋**이다.

YOLO의 역할은 외경을 직접 측정하는 것이 아니라, 전체 이미지에서 측정 대상 부위를 찾아 OpenCV 측정 단계로 전달하는 것이다.

### YOLO 데이터 구성

초기 원본 이미지에서 외경 측정 대상 부위를 Bounding Box로 Annotation하여 학습 데이터를 구성하였다.

초기 데이터는 다음과 같이 구성하였다.

- 원본 이미지: 10장
- 정상 시편 이미지: 7장
- NG 시편 이미지: 3장

데이터 부족을 보완하기 위해 이미지 증강을 적용하였다.

주요 증강 항목:

- Blur
- Brightness
- Contrast
- Dark
- 기타 촬영조건 변화

YOLO 학습 데이터의 기본 구조는 다음과 같다.

```text
04_YOLO_Dataset/
│
├─ images/
│   ├─ train/
│   └─ val/
│
├─ labels/
│   ├─ train/
│   └─ val/
│
└─ data.yaml
```

학습된 YOLO 모델은 다음 흐름에서 사용된다.

```text
원본 이미지
    ↓
YOLO ROI Detection
    ↓
측정부 ROI
    ↓
OpenCV Edge Detection
    ↓
31-point 외경 측정
```

따라서 YOLO는 **위치 탐색**, OpenCV는 **정밀 치수 측정** 역할을 담당한다.

## 7. 05_Calibration_Data

Pixel 단위의 외경 측정값을 실제 mm 단위로 변환하기 위한 Calibration 및 Validation 데이터를 관리한다.

### Calibration

초기 Calibration 시험에서는 기준 외경이 확보된 시편을 반복 촬영하여 Pixel과 실제 외경의 관계를 분석하였다.

### Validation

Calibration에 사용하지 않은 별도 시편을 이용하여 변환식의 정확도를 확인하였다.

### 주요 평가 지표

- Bias
- MAE
- Maximum Error
- STD
- CV
- OK/NG 판정 결과

프로젝트 진행 과정에서 스마트폰 촬영조건, 시편 위치, 반사, Edge 선택 등의 영향으로 Pixel 값이 변하는 문제가 확인되었다.

따라서 현재 Calibration은 기능적으로 구현되었으나 **±10 µm 공차 수준의 독립 정확도 검증이 완료된 상태는 아니다.**

---

## 8. 최신 정밀측정 ROI

3차 촬영 데이터 분석 과정에서 실제 외경 측정부를 다시 정의하였다.

```text
ROI = [8008, 3329, 8280, 4276]
```

ROI 폭:

```text
272 px
```

실제 축 방향 측정부 길이:

```text
10.2 mm
```

표면거칠기와 광학 Edge 비교에서는 중앙 5 mm 영역을 사용하였다.

```text
중심 기준
좌측 2 mm + 우측 3 mm = 총 5 mm
```

V3 측정엔진은 해당 ROI에서 31개의 측정 열을 생성하며, 실제 중앙 5 mm 범위에 포함되는 명목 측정열은 23개이다.

## 9. 데이터 사용 흐름

```text

        ↓
원본 촬영 이미지
        ↓

        ↓
Validation

```

## 10. 데이터 분석 시 유의사항

본 프로젝트에서 반복 촬영 과정 중 일부 이미지에서 Pixel 위치 변화와 Edge 오선택 가능성이 확인되었다.

따라서 데이터는 단순 평균값만 사용하지 않고 다음 항목을 함께 검토하였다.

- Median
- MAD
- STD
- Range
- CV
- Pin Pixel
- 이상 이미지
- Edge Overlay

특히 통계적 이상값 제거 결과는 측정 정확도 자체를 의미하지 않으며, 실제 영상의 Edge 위치와 촬영조건을 함께 확인해야 한다.

---

## 11. 데이터 단계의 주요 결과

본 데이터 구축을 통해 다음 사항을 확인하였다.

1. YOLO를 이용한 측정부 ROI 자동 검출 구조를 구축하였다.
2. OpenCV 기반 외경 Pixel 측정 데이터를 확보하였다.
3. Calibration 및 Validation 반복 데이터를 구축하였다.
4. 3차 촬영을 통해 반복 측정 데이터를 확대하였다.
5. 촬영조건과 Edge 선택이 정밀측정 결과에 큰 영향을 줄 수 있음을 확인하였다.
6. 표면거칠기는 잠재적인 영향요인이지만 현재 데이터만으로 직접적인 원인으로 확정할 수 없었다.
7. ±10 µm 수준의 최종 검증을 위해서는 산업용 광학계와 고정 지그를 적용한 추가 Pilot 검증이 필요하다.
