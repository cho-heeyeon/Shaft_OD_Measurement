# Raw Image Data

본 프로젝트에서는 샤프트 외경 자동측정 알고리즘 개발을 위해
실제 촬영된 샤프트 이미지를 사용하였다.

## 데이터 공개 범위

프로젝트에서 사용한 원본 이미지 전체는 실제 제품 및 생산환경과
관련된 정보를 포함할 수 있어 Public GitHub 저장소에는 공개하지 않는다.

저장소에는 프로젝트의 입력 영상 형태를 설명하기 위한
비식별화된 대표 이미지 1장만 공개한다.

## 주의사항

공개된 대표 이미지는 전체 데이터셋을 의미하지 않으며,
프로젝트에서 사용한 데이터의 구성과 학습·검증 사용 내역은
상위 `02_Data/README.md`에서 별도로 설명한다.
