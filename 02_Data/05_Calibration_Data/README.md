# Calibration Data

## 1. 목적

본 폴더는 YOLO + OpenCV 기반 샤프트 외경 측정 과정에서
영상의 Pixel 측정값을 실제 외경(mm)으로 변환하기 위해 수행한
Calibration 관련 내용을 정리한다.

---

## 2. Day020 Calibration

Day020 단계에서는 여러 기준 데이터를 이용하여
Pixel 측정값과 실제 측정값의 관계를 구하고,
이를 선형식으로 변환하는 다점 Calibration 구조를 검토하였다.

기본 변환식은 다음과 같다.

mm = a × pixel + b

여기서

- pixel : 영상에서 측정한 샤프트 외경
- mm : 실제 외경
- a : Calibration 기울기
- b : 보정값

을 의미한다.

다만 현재 보존된 결과자료만으로는
Day020에서 산출된 실제 a, b 값을 명확하게 확인할 수 없으므로
본 README에는 해당 수치를 임의로 기재하지 않는다.

## 3. Day027 최종 V1 Calibration

Day027 최종 End-to-End 데모에서는 `sample_07`을
Calibration 기준 샘플로 사용하였다.

확인된 기준값은 다음과 같다.

| 항목 | 값 |
|---|---:|
| Calibration sample | sample_07 |
| 기준 실측 외경 | 20.021 mm |
| Calibration Pixel | 464.06 px |
| 변환 기준 | 20.021 / 464.06 mm/px |

Pixel → mm 변환은 다음 관계를 이용하였다.

mm/px = 20.021 / 464.06

따라서 영상에서 측정된 Pixel 값에 위 변환계수를 적용하여
외경을 mm 단위로 환산하였다.

## 4. Day027 측정 결과

최종 기록에서 확인된 측정 결과는 다음과 같다.

| 항목 | 결과 |
|---|---:|
| 측정 Pixel | 464.0575 px |
| Vision 측정값 | 20.0209 mm |
| 기준 실측값 | 20.021 mm |
| 측정 오차 | -0.0001 mm |

도면 규격은 다음과 같다.

- 기준 외경 : Ø20.020 mm
- 공차 : ±0.010 mm
- 허용범위 : 20.010 ~ 20.030 mm

따라서 해당 데모 측정 결과인 20.0209 mm는
설정된 허용범위 내에 있으므로 OK로 판정되었다.

## 5. Calibration의 한계

Day027 최종 V1에서는 하나의 기준 샘플 `sample_07`의
실측값 20.021 mm와 영상 측정값 464.06 px를 이용하여
Pixel → mm 변환 기준을 설정하였다.

따라서 이 결과만으로 측정시스템이 ±0.010 mm 수준의
측정 정확도를 확보했다고 판단할 수는 없다.

특히 Calibration에 사용한 동일 샘플의 측정 결과가
기준값과 매우 가깝게 나타난 것은 Calibration 기준점에 대한
일치 결과이며, 독립적인 샘플에 대한 측정 정확도 검증과는 구분해야 한다.

실제 측정시스템의 정확도 및 양산 적용성을 평가하기 위해서는
Calibration에 사용하지 않은 독립 샘플을 이용한 검증과
반복 측정 데이터 확보가 추가로 필요하다.

## 6. End-to-End 시스템에서의 위치

Day027 최종 V1의 전체 처리 흐름은 다음과 같다.

이미지 입력
→ YOLO ROI 탐지
→ OpenCV Edge 검출
→ Sub-pixel 정밀화
→ 다점 측정 / Median 및 Outlier 처리
→ Pixel 외경 산출
→ Calibration
→ mm 변환
→ 20.010 ~ 20.030 mm 규격 비교
→ OK / NG 판정

Calibration은 영상처리에서 얻어진 Pixel 값을
실제 제조 현장에서 사용하는 mm 단위로 연결하는 단계이다.
