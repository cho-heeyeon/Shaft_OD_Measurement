# 성능평가 및 검증 한계 분석

## 1. 목적

본 단계에서는 YOLO + OpenCV 기반 샤프트 외경 자동측정 시스템의
개발 결과를 정리하고, 현재 확보된 데이터로 확인할 수 있는 성능과
추가 검증이 필요한 항목을 구분한다.

본 프로젝트에서는 다음 두 가지를 명확히 구분한다.

1. 시스템 기능 구현 여부
2. 측정시스템 성능 검증 여부

---

## 2. 평가 대상

본 프로젝트에서 구현한 전체 측정 흐름은 다음과 같다.

이미지 입력
→ YOLO ROI 탐지
→ OpenCV Edge 검출
→ 정밀 Edge 처리
→ Pixel 외경 측정
→ Calibration
→ mm 변환
→ 도면 규격 비교
→ OK / NG 판정

Day027에서는 위 과정이 연결된
End-to-End V1을 구현하였다.

---

## 3. 평가 기준

대상 샤프트의 도면 요구사항은 다음과 같다.

- 기준 외경 : Ø20.020 mm
- 공차 : ±0.010 mm
- 허용범위 : 20.010 ~ 20.030 mm

따라서 Vision 측정값이

20.010 mm ≤ 측정값 ≤ 20.030 mm

이면 OK,

범위를 벗어나면 NG로 판정한다.

---

## 4. 현재까지 확인된 사실

### 4.1 YOLO ROI 탐지

초기 YOLO ROI 탐지 실험에서는
confidence 약 0.008이 기록되었다.

이후 영상 증강 및 재학습을 진행하였으며,
Day027 End-to-End 실행에서는
YOLO confidence 0.784195가 기록되었다.

이를 통해 제한된 데이터 환경에서
YOLO ROI 탐지가 실제 End-to-End 파이프라인에서
동작하는 사례를 확인하였다.

단, 이 confidence 값은 해당 입력 영상에 대한
탐지 결과이며 실제 생산환경 전체의
YOLO 탐지성능을 의미하지 않는다.
---

### 4.2 OpenCV 외경 측정

OpenCV를 이용하여 ROI 내부에서
샤프트의 상·하 Edge를 검출하고
두 Edge 사이의 Pixel 거리를 이용하여
외경을 측정하는 구조를 구현하였다.

개발 과정에서는 금속 반사광, 가공무늬 및 배경 등의 영향으로
실제 외곽 Edge가 아닌 내부 Edge가 선택될 수 있는 문제가 발생하였다.

이를 개선하기 위해 다음 방법을 단계적으로 검토하였다.

- Gradient 방향
- Multi-point
- Median
- Outlier 처리
- Line Fitting
- Sub-pixel
- Edge 연속성

---

### 4.3 Pixel → mm 변환

Day027 End-to-End V1에서는
`sample_07`의 기준 실측값 20.021 mm와
Calibration Pixel 464.06 px를 이용하여
Pixel → mm 변환 기준을 설정하였다.

확인된 측정 결과는 다음과 같다.

| 항목 | 결과 |
|---|---:|
| 기준 실측값 | 20.021 mm |
| Calibration Pixel | 464.06 px |
| 측정 Pixel | 464.0575 px |
| Vision 측정값 | 20.0209 mm |
| 도면 허용범위 | 20.010 ~ 20.030 mm |
| 판정 | OK |

---

## 5. 계산으로 확인되는 사항

Day027 기준 샘플의 Vision 측정값과
기준 실측값의 차이는 다음과 같다.

20.0209 - 20.021 = -0.0001 mm

절대적인 차이는 약 0.0001 mm이다.

또한 20.0209 mm는

20.010 mm ≤ 20.0209 mm ≤ 20.030 mm

이므로 설정된 판정 로직에 따라 OK이다.

이 두 내용은 주어진 값을 이용한 계산 결과이다.

---

## 6. 이 결과를 '측정 정확도'로 해석할 수 없는 이유

Day027에서 사용한 `sample_07`은
Calibration 기준으로 사용한 샘플이다.

따라서 동일 기준점 부근의 결과인

기준 실측값 : 20.021 mm
Vision 측정값 : 20.0209 mm

의 차이가 작다는 사실만으로
전체 측정시스템의 정확도가 0.0001 mm라고 판단할 수 없다.

즉,

약 0.0001 mm 차이
≠
시스템 측정 정확도 ±0.0001 mm

이다.

또한 이 결과만으로
도면 공차 ±0.010 mm를 안정적으로 측정할 수 있다고
입증된 것도 아니다.

## 7. 데이터 규모의 한계

프로젝트에서 확보한 원본 샤프트 이미지는 총 10장이다.

일부 영상에서는 금속 반사광, 가공무늬, 배경 및 촬영조건 등의
영향으로 안정적인 외경 측정에 어려움이 발생하였다.

YOLO 단계에서는 6개의 원본 이미지 계열을 사용하였다.

각 원본 계열에

- orig
- blur
- bright
- contrast
- dark

변형을 적용하여 총 30장의 데이터셋을 구성하였다.

그러나 이 30장은 서로 다른 실물 샤프트 30개가 아니다.

Train은 5개 원본 계열에서 파생된 25장,
Validation은 `sample_07` 한 개 원본 계열에서 파생된 5장이다.

따라서 독립적인 신규 제품에 대한 일반화 성능을
검증한 데이터셋으로 해석할 수 없다.

## 8. 기존 성능 수치 재검토

프로젝트 정리 과정에서 기존 자료에 사용된 다음 성능 수치의
원본 근거를 개발 기록에서 다시 확인하였다.

- 96/100 허용범위
- 초과 4건
- MAE 0.0045 mm
- 최대 절대오차 0.016 mm

그러나 현재 보존된 개발 기록에서는
위 수치들을 산출한 100개 실제 측정 원자료와
해당 성능평가 계산 코드를 확인하지 못하였다.

`0.0045` 및 `0.016`과 유사한 값이
YOLO 학습 과정에서 생성된 `results.csv`에서 검색되었으나,
이는 외경 측정오차의 근거가 아니므로
측정시스템 성능평가에 사용하지 않는다.

또한 Day020에는 MAE 계산 코드가 존재하지만,
코드에 사용된 값이 실제 측정 데이터가 아닌
예시 데이터임이 코드 주석에서 확인되었다.

따라서 현재 근거가 확인되지 않은 위 수치들은
본 성능평가의 검증된 결과로 사용하지 않는다.

## 10. 현재 단계에서 평가 가능한 성과

현재 프로젝트에서 직접 확인할 수 있는 핵심 성과는
'양산 측정성능 검증 완료'가 아니라
자동측정 기능의 End-to-End 구현이다.

구현된 기능은 다음과 같다.

이미지 입력
→ ROI 자동탐지
→ 외곽 Edge 측정
→ Pixel 외경 계산
→ mm 변환
→ 규격 비교
→ OK / NG 판정

따라서 현재 단계의 성과는

**YOLO + OpenCV 기반 샤프트 외경 자동측정
End-to-End V1 시스템 구현**

으로 정의한다.

## 11. 추가 성능검증 계획

실제 측정시스템의 성능을 판단하기 위해서는
Calibration 데이터와 Validation 데이터를 분리해야 한다.

향후 검증은 다음 순서로 수행한다.

1. 신규 독립 샤프트 데이터 확보
2. 여러 기준 치수의 Calibration 데이터 구성
3. Calibration 모델 산출
4. Calibration에 사용하지 않은 Validation 샘플 측정
5. 기준 측정값과 Vision 측정값 비교
6. 샘플별 측정오차 계산
7. 반복 측정 실시
8. 제품 재장착 후 재측정
9. 조명 및 촬영조건 변화 시험
10. 측정시스템 분석 및 현장 적용성 판단

---

## 12. 최종 평가

현재 확보된 자료를 기준으로 다음과 같이 평가한다.

### 확인된 것

- YOLO 기반 ROI 탐지 구조 구현
- OpenCV 기반 외경 측정 구조 구현
- 정밀 Edge 처리 방법 적용
- Pixel → mm Calibration 구조 구현
- 도면 규격 기반 OK/NG 자동판정 구현
- End-to-End V1 실행

### 아직 확인되지 않은 것

- ±0.010 mm 수준의 양산 측정성능
- 다양한 제품에 대한 일반화 성능
- 반복 측정 안정성
- 제품 재장착 영향
- 실제 생산환경에서의 장기 안정성

따라서 본 프로젝트는

**자동측정 시스템의 기술 구현 및 가능성을 확인한 단계**

이며,

**양산 적용을 위한 최종 측정성능 검증 단계와는 구분한다.**
