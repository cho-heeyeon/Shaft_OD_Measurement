
# 1차 측정 Calibration

## 1. 목적

기본 Pixel → mm Calibration 기능을 구현한 이후, 실제 샤프트 촬영영상에 Calibration 구조를 적용하여 실제 측정환경에서도 사용할 수 있는지 확인하였다.

1차 측정의 핵심 목적은 다음과 같다.

- 실제 촬영영상에서 Pixel 외경 측정
- 실제 계측값과 Pixel 값의 대응 가능성 확인
- 반복 촬영 시 Pixel 측정 안정성 확인
- 촬영조건이 Calibration에 미치는 영향 확인

---

## 2. 기본 측정 구조

1차 측정에서는 다음과 같은 흐름으로 외경을 측정하였다.

```text
샤프트 이미지
    ↓
ROI 설정
    ↓
OpenCV Edge 검출
    ↓
상·하 Edge 거리 계산
    ↓
Pixel 외경
    ↓
Calibration
    ↓
mm 외경
```

초기 단계에서는 영상에서 검출된 Pixel 외경과 실제 계측기로 측정한 기준값을 대응하여 Pixel → mm 변환 가능성을 확인하였다.

---

## 3. 확인된 주요 문제

실제 촬영영상에 Calibration을 적용하면서 단순한 변환계수만으로는 정밀측정 안정성을 확보하기 어렵다는 점을 확인하였다.

주요 영향요인은 다음과 같다.

### 3.1 촬영거리와 배율

카메라와 샤프트 사이의 촬영거리가 달라질 경우 동일한 실제 외경이라도 영상상의 Pixel 크기가 달라질 수 있다.

따라서 Calibration 이후에도 촬영거리가 변하면 기존 변환계수를 그대로 적용하기 어렵다.

### 3.2 시편 위치 및 높이

시편의 위치와 카메라 광축에 대한 높이 차이도 Pixel 측정값에 영향을 줄 가능성이 확인되었다.

특히 일반 렌즈를 사용하는 스마트폰 촬영에서는 시편의 Z 방향 위치 변화가 영상 배율 변화로 이어질 수 있다.

### 3.3 ROI 위치

측정 ROI가 실제 외경 관리 부위와 정확하게 일치하지 않을 경우, 실제 계측값과 영상 측정값의 비교가 불안정해질 수 있다.

### 3.4 Edge 오선택

샤프트 표면의 반사와 명암 변화로 인해 실제 외곽 Edge 대신 내부의 강한 명암 경계를 선택하는 문제가 발생할 수 있었다.

이 경우 Pixel 외경 자체가 잘못 측정되므로 Calibration 수식이 정확하더라도 최종 mm 값은 신뢰하기 어렵다.

---

## 4. 1차 측정의 판단

1차 측정을 통해 Pixel 값을 mm 단위로 변환하는 Calibration 기능 자체는 적용 가능함을 확인하였다.

그러나 정밀측정에서는 단순한 `mm/pixel` 변환계수보다 다음 조건이 더 중요하다고 판단하였다.

- 동일 촬영거리 유지
- 동일 촬영배율 유지
- 동일 시편 높이 유지
- 실제 측정부와 ROI 일치
- 실제 외곽 Edge의 안정적인 선택
- 반복 촬영 Pixel 값의 안정성 확보

즉,

> Calibration 수식보다 먼저 측정 Pixel 값 자체가 물리적으로 안정되어야 한다.

는 점이 1차 측정의 핵심 결과이다.

---

## 5. 다음 단계로의 개선 방향

1차 측정에서 확인된 한계를 바탕으로 다음 단계에서는 단일 기준점 변환에서 벗어나 복수 시편을 이용한 Calibration과 Validation 구조를 검토하였다.

주요 개선 방향은 다음과 같다.

1. 복수 시편의 실제 외경값 확보
2. 각 시편의 Pixel 외경 측정
3. Pixel ↔ 실제 외경 관계 확인
4. Calibration용 시편과 Validation용 시편 분리
5. Multi-point Edge 측정
6. Median 기반 대표값 산출
7. Edge 오선택 문제 개선

이를 통해 2차 측정에서는 단순한 변환 기능이 아니라 **Calibration 모델과 독립적인 Validation 구조**를 구축하는 방향으로 발전하였다.

---

## 6. 결론

1차 측정에서는 기본 Calibration 기능을 실제 샤프트 촬영영상에 적용하고, Pixel → mm 변환의 가능성과 한계를 확인하였다.

이 과정에서 촬영거리, 시편 위치, ROI 및 Edge 선택 조건이 Pixel 측정값에 직접적인 영향을 줄 수 있음을 확인하였다.

따라서 1차 측정은 최종 Calibration 정확도를 검증한 단계가 아니라,

> **실제 촬영환경에서 Calibration 성능을 제한하는 물리적·영상처리 조건을 확인한 초기 검증 단계**

로 정리한다.
