# YOLO 기반 ROI 자동탐지

## 1. 목적

본 단계에서는 샤프트 외경 측정에 필요한 ROI(Region of Interest)를
영상에서 자동으로 탐지하기 위해 YOLO를 적용하였다.

OpenCV 기반 초기 측정에서는 측정영역을 좌표로 직접 지정하였다.

그러나 실제 공정에서는 샤프트가 가공 전에 척 죠에 체결되고
가공 후 외경을 측정하게 된다.

척 죠 체결 시 제품의 영상상 위치가 변화할 가능성은 있으나,
본 프로젝트에서는 실제 체결 위치 변화량 및 그 변화가
영상 좌표에 미치는 영향을 별도의 데이터로 검증하지 못하였다.

따라서 본 프로젝트의 YOLO 적용 목적은
'척 죠 체결 위치 변화가 확인되었기 때문'이 아니라,
고정 좌표에 의존하지 않고 영상에서 측정영역을 자동으로
탐지할 수 있는 구조의 가능성을 검토하는 것으로 정의하였다.

---

## 2. YOLO의 역할

본 시스템에서 YOLO는 샤프트의 외경을 직접 측정하지 않는다.

YOLO의 역할은 전체 영상에서
외경 측정에 필요한 ROI를 탐지하는 것이다.

전체 처리 개념은 다음과 같다.

이미지 입력
→ YOLO ROI 탐지
→ ROI 추출
→ OpenCV Edge 검출
→ 정밀 Edge 위치 계산
→ Pixel 외경 측정
→ Calibration
→ mm 변환
→ OK / NG 판정

따라서 본 프로젝트에서는

- YOLO : 측정영역 탐지
- OpenCV : 실제 외경 측정

으로 역할을 구분하였다.

## 4. 초기 ROI 탐지 실험

초기 YOLO ROI 탐지 실험에서는
ROI confidence가 약 0.008 수준으로 나타났다.

이 결과에서는 ROI를 안정적으로 탐지하기 어렵다고 판단하였다.

이 단계에서 제한된 원본 데이터 규모가
YOLO 학습 성능에 영향을 줄 가능성을 고려하여
데이터 증강을 적용하였다.

단, confidence가 낮은 원인을 데이터 부족 하나로
단정할 수는 없다.

---

## 5. 데이터 증강

제한된 원본 데이터를 보완하기 위해
각 원본 이미지에 영상 변형을 적용하였다.

사용한 변형은 다음과 같다.

- orig : 원본
- blur : 흐림 변형
- bright : 밝기 증가
- contrast : 대비 변화
- dark : 밝기 감소

데이터 구성 결과:

| 구분 | 원본 계열 | 증강 포함 |
|---|---:|---:|
| Train | 5개 | 25장 |
| Validation | 1개 | 5장 |
| 합계 | 6개 | 30장 |

30장은 서로 다른 샤프트 30개가 아니라
6개 원본 이미지 계열에서 파생된 데이터이다.

## 7. ROI 탐지 결과

개발기록에 따르면 초기 실험에서는
ROI confidence가 약 0.008 수준이었다.

데이터 증강 및 재학습 이후 실험에서는
최고 confidence 약 0.784가 기록되었다.

따라서 제한된 데이터 환경에서
YOLO를 이용한 ROI 탐지가 동작하는 사례를 확인하였다.

다만 최고 confidence 0.784는
전체 데이터에 대한 일반화 성능이나
실제 생산환경에서의 ROI 탐지 성능을 의미하지 않는다.

---

## 8. 중복 Bounding Box 처리

YOLO 추론 과정에서 하나의 영상에
여러 Bounding Box가 검출될 수 있으므로,
검출 결과 중 가장 높은 confidence를 가진
Bounding Box 1개를 선택하도록 처리하였다.

처리 개념은 다음과 같다.

YOLO Detection
→ 복수 Bounding Box
→ Confidence 비교
→ 최고 Confidence Box 선택
→ 측정 ROI 사용

이를 통해 이후 OpenCV 측정 단계에 전달할
ROI를 하나로 결정하였다.

---

## 9. 결과 해석 및 한계

본 실험을 통해 제한된 데이터 환경에서
YOLO 기반 ROI 자동탐지 구조를 구현하였다.

그러나 다음과 같은 한계가 존재한다.

1. 원본 이미지 계열이 6개로 제한되어 있다.
2. 총 30장은 독립된 30개 제품이 아니라 증강 데이터이다.
3. Validation 5장도 하나의 sample_07 원본에서 파생되었다.
4. 다양한 실제 생산조건에서의 일반화 성능은 검증하지 못하였다.
5. 척 죠 체결 위치 변화량과 영상 좌표 변화의 관계는 검증하지 못하였다.

따라서 본 결과는 실제 양산 적용 성능의 검증 결과가 아니라
제한된 데이터에서 YOLO ROI 자동탐지의
기술적 구현 가능성을 확인한 결과로 해석한다.
