# 프로젝트 수행 후 선행연구 검토

## 1. 검토 목적

본 프로젝트는 YOLO + OpenCV 기반 샤프트 외경 자동측정 시스템을
구현한 후 관련 선행연구를 본격적으로 검토하였다.

따라서 본 문헌 검토는 프로젝트 시작 전 기술선정을 위한
선행연구 조사가 아니라,

**프로젝트 수행 과정에서 경험한 문제와 적용한 기술이 기존 연구에서
어떻게 다루어지고 있는지를 사후 비교·검증하기 위한 검토**

로 정의한다.

이러한 수행 순서를 명확하게 기록함으로써 프로젝트에서 직접
확인한 내용과 기존 연구에서 이미 검증된 내용을 구분한다.

---

## 2. 프로젝트에서 먼저 경험한 기술적 문제

프로젝트에서는 샤프트 이미지로부터 외경을 자동 측정하기 위해

YOLO ROI 탐지
→ OpenCV Edge 검출
→ 정밀 Edge 처리
→ Pixel 외경 측정
→ Calibration
→ mm 변환
→ OK/NG 판정

순으로 개발하였다.

개발 과정에서 다음과 같은 문제를 경험하였다.

- 금속 표면의 반사광
- 가공무늬에 의한 내부 Edge 발생
- 배경과 실제 외곽 Edge의 구분 문제
- 촬영조건에 따른 Edge 위치 변화
- ROI 자동탐지의 불안정성
- Pixel 단위 측정값의 mm 변환 문제
- 단일 기준값 Calibration의 한계

이 문제들을 개선하기 위해 개발 과정에서

→ Edge 오검출
→ 다점 측정
→ Median 기반 안정화
→ Line Fitting
→ Sub-pixel
→ Calibration

등을 단계적으로 검토·적용하였다.

## 3. 주요 선행연구

### 3.1 Measurement of shaft diameters by machine vision

- 저자: Guang Wei, Qingchang Tan
- 저널: Applied Optics
- 발표: 2011
- DOI: 10.1364/AO.50.003246

이 연구는 머신비전을 이용하여 원통형 샤프트의 직경을
측정하는 방법을 제안하였다.

Perspective projection과 원통형 샤프트의 기하학적 특성을
모델링하였으며, 알려진 직경의 샤프트를 이용하여 일부
모델 파라미터를 결정하였다.

또한 카메라 모델에서 radial distortion과 tangential distortion을
고려하고 카메라와 샤프트의 상대적인 위치 등이
측정 정확도에 미치는 영향을 실험하였다.

### 프로젝트와의 관계

본 프로젝트에서도 Pixel 정보를 실제 mm 단위로 변환하기 위해
기준 실측값을 이용한 Calibration이 필요하였다.

또한 향후 실제 측정시스템에서는 제품 위치와 카메라 설치조건이
측정결과에 미치는 영향을 검증해야 한다는 점에서
본 프로젝트의 향후 검증과 직접 관련된다.

### 3.2 A measurement method for the diameter of aero-engine
transmission shafts based on telecentric line-scan imaging

- 저널: Measurement Science and Technology
- 발표: 2025
- DOI: 10.1088/1361-6501/ae17e1

이 연구에서는 에어로엔진 transmission shaft의 직경 측정을 위해
line-scan camera와 telecentric lens를 이용한 비접촉 측정시스템을
구성하였다.

샤프트의 투영 윤곽 영상을 획득하고 양쪽 Edge point를 추출한 후,
양쪽 Edge를 각각 직선으로 fitting하여 평행한 두 직선 사이의
거리를 이용해 직경을 계산하였다.

또한 imaging distortion, motion speed fluctuation,
lens manufacturing imperfection 등의 영향을 보정하기 위한
Calibration 방법을 적용하였다.

논문에서는 기준 직경 28.002 mm인 샤프트에 대해
28.010 mm의 측정값과 0.002 mm의 표준편차를 보고하였다.

### 프로젝트와의 관계

본 프로젝트의 개발 과정에서도 단일 위치 Edge에 의존할 경우
금속 반사광과 가공무늬 등의 영향을 받을 수 있음을 경험하였다.

이에 따라 여러 Edge 정보를 이용하고 Line Fitting 등을 적용하여
안정적인 외곽선을 얻는 방법을 검토하였다.

프로젝트 완료 후 선행연구를 확인한 결과,
Edge point를 다수 확보하여 선형 fitting을 수행하는 접근이
정밀 샤프트 직경 측정 연구에서도 사용되고 있음을 확인하였다.

### 3.3 Enhancing Diameter Measurement Accuracy
in Machine Vision Applications

- 저자: Ahmet Gökhan Poyraz 외
- 저널: Measurement
- Volume 278
- Article 121646
- 발표: 2026
- DOI: 10.1016/j.measurement.2026.121646

이 연구는 좁은 공차를 가진 부품의 머신비전 직경 측정에서
발생하는 측정오차를 개선하는 방법을 다루었다.

산업용 카메라와 telecentric lens를 이용하였으며,
여러 개의 알려진 기준 부품을 이용하는 두 가지 접근법을 제안하였다.

- Conversion factor 기반 방법
- Pixel 기반 방법

또한 Sub-pixel 기반 직경 측정을 적용하였다.

실험은 유리 샘플 1~12 mm와 금속 부품 3~24 mm를 대상으로
수행되었으며, 논문에서는 기존 13~114 μm 수준의 측정오차를
제안 방법을 통해 약 1~2 μm 수준으로 감소시켰다고 보고하였다.

### 프로젝트와의 관계

본 프로젝트에서는 제한된 데이터로 인해 최종적으로 하나의
기준 실측값에 의존한 Calibration을 사용하였다.

따라서 동일 기준점 부근에서는 좋은 결과가 나타날 수 있지만,
다른 직경에서도 동일한 변환관계가 유지되는지는 검증하지 못하였다.

이 선행연구는 여러 알려진 기준 부품을 사용하는 Calibration이
측정범위 전체의 정확도 향상에 중요할 수 있음을 보여준다.

## 5. 선행연구 검토 후 확인된 사실

프로젝트에서 사용한

- Edge Detection
- Line Fitting
- Sub-pixel
- Calibration
- 다점 기반 측정

등의 접근은 머신비전 정밀 치수측정 분야에서 이미 연구되어 온
기술적 접근과 상당 부분 연결된다.

따라서 이러한 기술 자체를 본 프로젝트에서 새롭게 제안한
측정원리 또는 새로운 알고리즘이라고 주장하지 않는다.

## 6. 프로젝트의 기술개발적 의미

본 프로젝트의 의미는 새로운 정밀측정 원리를 제안했다는 데
있지 않다.

제한된 실제 샤프트 데이터를 이용한 개발 과정에서

반사광 및 가공무늬
→ Edge 오검출
→ 다점 측정
→ Median 기반 안정화
→ Line Fitting
→ Sub-pixel
→ Calibration

이라는 문제 해결 과정을 직접 경험하였다.

그리고 프로젝트 완료 후 선행연구를 검토한 결과,
이러한 문제와 개선방향이 기존 머신비전 정밀측정 연구에서도
중요하게 다루어진 기술요소임을 확인하였다.

따라서 본 프로젝트의 연구개발적 의미는

**기존 정밀측정 기술요소를 실제 샤프트 영상에 적용하고,
YOLO 기반 ROI 자동탐지와 OpenCV 기반 정밀측정을 결합하여
이미지 입력부터 mm 변환 및 OK/NG 판정까지 연결되는
End-to-End V1을 구현했다는 점**

으로 정의한다.

## 7. 선행연구를 프로젝트 전에 검토하지 못한 영향

프로젝트 수행 전에 충분한 선행연구 검토가 이루어졌다면

- Telecentric Lens 필요성
- 복수 기준물 Calibration
- 카메라와 제품의 기하학적 위치 영향
- Line Fitting
- Sub-pixel 측정
- 독립 Validation

등을 초기 시스템 설계 단계부터 검토할 수 있었을 것이다.

따라서 본 프로젝트는 일부 기술적 문제를 개발 과정에서
시행착오를 통해 확인한 한계가 있다.

반면 이러한 과정을 개발기록으로 보존함으로써
어떤 문제가 실제 영상에서 발생했고 어떤 방식으로
개선 방향을 찾아갔는지를 확인할 수 있다.

## 8. 선행연구 검토에 따른 프로젝트 재해석

### 프로젝트에서 확인한 것

- 실제 샤프트 영상에서 Edge 불안정 문제가 발생함
- YOLO를 이용한 ROI 자동탐지 구조 구현
- OpenCV 기반 Edge 측정 구조 구현
- 정밀 Edge 처리 방법 적용
- Pixel → mm 변환 구조 구현
- 도면 규격 기반 OK/NG 판정 구현
- End-to-End V1 구현

### 선행연구를 통해 확인한 것

- 샤프트 직경 머신비전 측정 자체는 기존 연구 분야임
- Calibration은 정밀측정의 핵심 요소임
- 제품과 카메라의 위치관계가 측정에 영향을 줄 수 있음
- Line Fitting은 샤프트 Edge 측정에 활용된 기존 접근임
- Sub-pixel은 정밀 직경 측정에 활용되는 기존 접근임
- Telecentric optics가 정밀측정에 활용되고 있음
- 복수 기준물을 이용한 Calibration 개선 연구가 존재함

### 아직 검증하지 못한 것

- 본 시스템의 ±0.010 mm 양산 측정능력
- 독립 샤프트에 대한 측정 정확도
- 반복 측정 안정성
- 제품 재장착에 따른 영향
- 카메라·제품 위치 변화 영향
- 실제 생산환경에서의 장기 안정성

## 9. 향후 개선 방향

선행연구 검토 결과를 향후 시스템 개발에 반영할 경우
다음과 같은 순서로 개선할 필요가 있다.

1. 측정 요구사항 및 목표 측정불확도 설정
2. 카메라·렌즈·조명 등 광학계 재검토
3. Telecentric Lens 적용 필요성 검토
4. 복수의 알려진 직경 기준물 확보
5. Multi-point Calibration 구축
6. 독립 Validation 데이터 확보
7. Line Fitting 및 Sub-pixel 알고리즘 정량 비교
8. 제품 위치 변화 및 재장착 시험
9. 반복 측정 안정성 평가
10. 실제 생산환경 Pilot Test

## 10. 결론

본 프로젝트는 선행연구를 충분히 검토한 후 동일 기술을
재현하는 방식으로 시작된 프로젝트가 아니다.

실제 샤프트 영상을 이용하여 자동측정 시스템을 개발하는 과정에서
여러 측정 문제를 경험하고 개선방법을 단계적으로 적용한 후,
프로젝트 완료 단계에서 관련 선행연구와 비교하였다.

그 결과 프로젝트에서 경험한 주요 문제와 개선방법 중 상당 부분이
기존 머신비전 정밀측정 연구에서 다루어진 기술요소와
연결된다는 것을 확인하였다.

따라서 본 프로젝트의 결과를 새로운 측정원리의 개발로
주장하지 않는다.

대신,

**YOLO ROI 자동탐지와 OpenCV 정밀측정 기술을 결합하여
샤프트 이미지 입력 → ROI → Edge → Pixel → mm → OK/NG로
연결되는 End-to-End V1을 구현하고, 실제 개발과정에서 확인한
문제점을 선행연구와 비교하여 향후 정밀측정 시스템의
개선방향을 도출한 프로젝트**

로 정리한다.
