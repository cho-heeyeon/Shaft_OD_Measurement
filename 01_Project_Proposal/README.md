
01. 프로젝트 제안
프로젝트명
YOLO + OpenCV 기반 자동차 조향장치 샤프트 외경 자동측정 시스템
제안 배경
자동차 조향장치용 샤프트의 외경은 제품 기능과 조립 품질에 직접 영향을 주는 중요 관리 치수이다.

기존에는 마이크로미터 등 접촉식 측정기에 의존하여 작업자가 직접 측정하는 경우가 많으며, 측정 위치·측정 압력·작업자 숙련도에 따라 결과가 달라질 수 있다.

본 프로젝트에서는 스마트폰 또는 카메라로 촬영한 샤프트 영상을 이용하여 측정부를 자동으로 검출하고, OpenCV 기반 Edge 분석을 통해 외경을 자동 측정하는 비전 기반 측정 시스템의 구현 가능성을 검토하였다.
프로젝트 목표
- YOLO를 이용한 샤프트 측정부 ROI 자동 검출
- OpenCV를 이용한 상·하 Edge 검출
- 영상 기반 외경 Pixel 측정
- Pixel-to-mm Calibration
- 도면 규격과 비교한 OK/NG 자동 판정
- 반복 측정 및 정밀도 평가
- End-to-End 자동측정 프로토타입 구현
측정 대상
- 자동차 조향장치용 샤프트
- 기준 외경: Ø20.020 mm
- 공차: ±0.010 mm
- 허용 범위: 20.010 ~ 20.030 mm
제안 단계의 시스템 구성
샤프트 이미지 촬영
        ↓
YOLO ROI 검출
        ↓
OpenCV Edge 검출
        ↓
외경 Pixel 계산
        ↓
Pixel-to-mm Calibration
        ↓
OK / NG 판정
제안 발표자료
본 폴더에는 2026-09-21 프로젝트 제안 발표자료를 보관한다.

제안 발표자료는 프로젝트 착수 시점의 문제 정의, 목표, 기술 접근방법, 실험계획, 평가방법 및 개발 일정을 정리한 자료이다.

프로젝트 진행 이후의 실제 개발 결과와 성능 검증 내용은 다음 폴더에서 단계별로 확인할 수 있다.
- 02_Data : YOLO 학습 데이터 및 측정·검증 데이터
- 03_OpenCV_Measurement : OpenCV 기반 외경 측정
- 04_YOLO_ROI : YOLO ROI 검출
- 05_Precision_Measurement : 정밀 측정 알고리즘 개선
- 06_Calibration : Pixel-to-mm Calibration
- 07_End_to_End : 전체 측정 파이프라인
- 08_Performance_Evaluation : 반복성 및 성능 평가
- 10_Final_Report : 최종 프로젝트 보고서
- 11_Presentation : 최종 발표자료
