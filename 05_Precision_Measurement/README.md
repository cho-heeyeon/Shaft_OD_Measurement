# OpenCV 기반 정밀 외경 측정 고도화

## 1. 목적

YOLO에서 탐지한 ROI 내부에서 샤프트의 실제 외곽 Edge를
보다 안정적으로 검출하고 외경을 정밀하게 측정하기 위해
OpenCV 기반 측정 알고리즘을 단계적으로 개선하였다.

YOLO는 측정영역을 찾는 역할을 수행하며,
실제 외경 계산은 ROI 내부의 OpenCV 영상처리를 통해 수행한다.

---

## 2. 기본 Edge 측정의 문제

초기 OpenCV 측정에서는 ROI 내부의 밝기 변화가 큰 위치를
Edge 후보로 검출하였다.

그러나 실제 샤프트 영상에는 다음과 같은 요소가 존재하였다.

- 금속 표면의 반사광
- 가공무늬
- 밝기 변화
- 배경과 제품의 경계
- 실제 외곽선 이외의 내부 Edge

따라서 밝기 변화가 크다는 이유만으로 Edge를 선택하면
실제 샤프트 외곽선이 아닌 내부 Edge가 선택될 수 있었다.

즉,

Gradient가 크다
→ Edge 후보가 될 수 있다
→ 그러나 반드시 실제 샤프트 외곽은 아니다.

라는 문제가 있었다.

---

## 3. Gradient 방향 활용

Gradient는 영상에서 밝기가 어느 방향으로,
얼마나 빠르게 변화하는지를 나타낸다.

샤프트 외곽에서는 일반적으로

배경 → 샤프트

또는

샤프트 → 배경

으로 밝기가 변화한다.

상단 Edge와 하단 Edge는 밝기 변화 방향이 서로 다를 수 있으므로,
Gradient의 부호와 방향을 이용하여 Edge 후보를 구분하였다.

이를 통해 단순히 Gradient 크기만 사용하는 것보다
상단 및 하단 Edge 후보를 구분할 수 있도록 개선하였다.

단, Gradient 방향만으로 모든 내부 Edge를 제거할 수 있는 것은 아니다.

---

## 4. Multi-point 측정

한 지점에서만 외경을 측정하면
반사광이나 국부적인 가공무늬의 영향을 크게 받을 수 있다.

따라서 ROI 내부의 여러 위치에서
상단 Edge와 하단 Edge를 각각 검출하고
여러 개의 외경값을 계산하는 Multi-point 방식을 적용하였다.

예:

Position 1 → 외경 1
Position 2 → 외경 2
Position 3 → 외경 3
...
Position N → 외경 N

이를 통해 한 지점의 잘못된 Edge 검출이
전체 측정값을 결정하는 문제를 줄이고자 하였다.

---

## 5. Median 적용

여러 위치에서 측정한 값 중 일부에는
반사광이나 Edge 오검출로 인해 비정상적인 값이 포함될 수 있다.

단순 평균은 이러한 큰 이상값의 영향을 받을 수 있으므로,
측정값을 정렬한 후 중앙값(Median)을 대표값으로 사용하는 방법을 적용하였다.

Median은 일부 극단적인 측정값이 존재하는 경우
평균보다 이상값의 영향을 적게 받는 장점이 있다.

---

## 6. Outlier 처리

Multi-point 측정값 중 대표적인 측정분포에서
크게 벗어난 값은 Outlier 후보로 판단하였다.

Outlier 처리를 통해

내부 Edge 오검출
→ 비정상적인 외경값 발생
→ 대표값 왜곡

의 영향을 줄이고자 하였다.

단, 정상값과 Outlier를 구분하는 기준은
실제 측정 데이터의 분포와 함께 검증해야 한다.

---

## 7. Line Fitting

각 위치에서 검출된 Edge 좌표는
반사광, 노이즈 및 가공무늬 등에 의해 흔들릴 수 있다.

따라서 여러 Edge 점을 하나의 선으로 근사하는
Line Fitting을 적용하여 외곽선의 전체적인 방향을 추정하였다.

개념적으로는 다음과 같다.

개별 Edge 점
→ 여러 점 수집
→ Line Fitting
→ 대표 Edge Line 추정

이를 상단 및 하단 Edge에 각각 적용하면
개별 Pixel 위치의 흔들림보다
전체 Edge 형태를 이용하여 외곽 위치를 추정할 수 있다.

---

## 8. Sub-pixel Edge

일반적인 영상 좌표는 Pixel 단위이다.

예를 들어 Edge 위치를

y = 200 pixel
y = 201 pixel

과 같이 정수 Pixel 단위로만 결정하면
한 Pixel보다 작은 위치 차이를 직접 표현할 수 없다.

정밀 외경 측정을 위해 Gradient 주변의 밝기 변화를 이용하여
Edge 위치를 Pixel 이하 수준으로 추정하는
Sub-pixel 방법을 적용하였다.

예:

기존 Pixel Edge
200 pixel

Sub-pixel Edge
200.xxx pixel

Sub-pixel은 영상의 물리적 해상도를 증가시키는 기술이 아니라,
기존 Pixel 주변의 영상정보를 이용하여
Edge 위치를 보다 세밀하게 추정하는 방법이다.

---

## 9. Edge 연속성 검토

실제 샤프트 외곽 Edge는 ROI의 한 지점에만 존재하는 것이 아니라
인접한 위치에서도 일정한 형태로 이어지는 특성을 가진다.

따라서 특정 위치에서 강한 Gradient가 검출되었다는 이유만으로
실제 외곽으로 판단하지 않고,
인접 위치에서도 유사한 Edge가 지속되는지를 검토하였다.

이러한 연속성 정보는
반사광이나 가공무늬로 인해 국부적으로 발생하는
내부 Edge와 실제 외곽 Edge를 구분하는 보조정보로 활용할 수 있다.

---

## 10. 정밀측정 처리 흐름

본 프로젝트에서 검토한 정밀측정 구조를 정리하면 다음과 같다.

YOLO ROI 탐지
→ ROI 추출
→ Gradient 계산
→ 상·하 Edge 후보 검출
→ 실제 외곽 Edge 선택
→ Multi-point 측정
→ Median / Outlier 처리
→ Line Fitting
→ Sub-pixel Edge 정밀화
→ Pixel 외경 계산
→ Calibration
→ mm 변환

---

## 11. 기술적 의미

본 개발과정에서 확인한 핵심은
단순히 가장 강한 Edge를 선택하는 것만으로는
금속 샤프트의 실제 외곽을 안정적으로 측정하기 어렵다는 점이다.

따라서 외경 측정에서는

- Edge의 강도
- Gradient 방향
- 여러 위치의 측정결과
- Edge의 공간적 연속성
- 이상값 여부
- Edge Line의 전체적인 형태
- Sub-pixel 위치

등을 함께 고려하는 방향으로 알고리즘을 개선하였다.

---

## 12. 결과 해석 시 주의사항

본 단계에서 적용한 방법들은
제한된 프로젝트 영상에서 측정 안정성을 개선하기 위해
단계적으로 검토한 방법이다.

따라서 각 기술이 측정오차를 각각 몇 mm 감소시켰는지,
또는 어떤 기술이 최종 성능 향상에 몇 % 기여했는지는
별도의 독립적인 비교실험으로 확인하지 않았다.

또한 입력 데이터가 제한되어 있으므로
다양한 실제 생산조건에서 동일한 성능이 유지된다고
판단할 수 없다.

따라서 본 결과는 정밀측정 알고리즘의
개발 및 기술적 가능성 확인 결과로 해석한다.
