# Multi-point 외경 측정

## 1. 실험 목적

샤프트 외경을 한 지점에서만 측정하지 않고,
가로 방향 여러 위치에서 측정하여 대표 외경을 계산하였다.

## 2. 측정 방법

1. ROI 이미지 입력
2. Gray 변환
3. Gaussian Blur 적용
4. Canny Edge 검출
5. 중앙 측정 영역 설정
6. 가로 방향 7개 측정 위치 선정
7. 각 위치에서 상단/하단 Edge 검출
8. 상단과 하단 Edge 사이 Pixel 거리 계산
9. 7개 외경 측정값의 중앙값을 대표값으로 사용

## 3. 결과 이미지 표시

- 빨간 점: 상단 Edge
- 파란 점: 하단 Edge
- 초록선: 상단 Edge와 하단 Edge 사이의 외경 측정 구간
- 총 7개 위치에서 외경 측정

## 4. Calibration

실제 계측기 외경값과 대표 Pixel 외경을 이용하여
다음과 같이 초기 Pixel → mm 환산계수를 계산하였다.

mm_per_pixel = actual_mm / median_pixel

이 단계는 하나의 기준값을 이용한 초기 1점 Calibration이다.

## 5. 실행 결과

결과 이미지에는 `Diameter: 20.020 mm`가 표시되었다.

단, 이 값은 동일 영상의 대표 Pixel 값과 입력된 실제 계측값으로
환산계수를 계산한 결과이므로 독립적인 측정 정확도 검증 결과로
해석하지 않는다.

## 6. 의미

단일 위치 측정에서 여러 위치를 이용한 Multi-point 측정으로
확장한 단계이다.

이후 단계에서는 Edge 검출 안정성, 대표값 선정,
Sub-pixel 측정 등의 정밀측정 방법을 추가로 검토하였다.
