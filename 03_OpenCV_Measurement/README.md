# OpenCV 기반 샤프트 외경 측정

## 1. 목적

본 단계에서는 샤프트 영상에서 외경을 측정하기 위한
OpenCV 기반 영상처리 방법을 구현하고 측정 가능성을 검토하였다.

YOLO 기반 ROI 자동탐지를 적용하기 전에,
지정된 측정영역(ROI)에서 샤프트의 상·하 외곽 Edge를 검출하고
두 Edge 사이의 Pixel 거리를 계산하는 기본 측정 구조를 구성하였다.

---

## 2. 기본 측정 원리

OpenCV 기반 외경 측정의 기본 처리 흐름은 다음과 같다.

이미지 입력
→ ROI 설정
→ Grayscale 변환
→ 영상 전처리
→ Edge 검출
→ 상·하 Edge 탐색
→ Edge 간 Pixel 거리 계산
→ 샤프트 외경 Pixel 값 산출

이 단계의 목적은 mm 단위의 최종 측정값을 바로 산출하는 것이 아니라,
영상에서 샤프트의 실제 외곽 위치를 안정적으로 검출할 수 있는지
확인하는 것이다.

---

## 3. ROI 설정

전체 영상에는 샤프트 외에도 배경, 척, 설비 및 기타 구조물이
포함될 수 있으므로 외경 측정에 필요한 영역을 ROI로 제한하였다.

초기 단계에서는 ROI 좌표를 직접 지정하여
측정영역을 설정하였다.

ROI를 사용하면 전체 영상에서 Edge를 탐색하는 것보다
불필요한 배경정보를 줄이고 샤프트 외곽 검출에 집중할 수 있다.

다만 실제 생산환경에서 샤프트의 영상상 위치가 변할 경우
고정 ROI만으로는 동일한 측정부위를 안정적으로 확보하기 어려울
가능성이 있다.

본 프로젝트에서 척 죠 체결 위치 변화가 영상 좌표에 미치는
실제 변화량은 별도의 데이터로 검증하지 못하였다.

따라서 위치 변화의 크기와 고정 ROI의 한계는
본 프로젝트에서 확인된 사실이 아니라 추가 검증이 필요한 항목이다.

---

## 4. Edge 기반 외경 측정

ROI 내부에서 샤프트와 배경 사이의 밝기 변화 등을 이용하여
외곽 Edge 후보를 검출하였다.

검출된 Edge 중 샤프트의 상단 및 하단 외곽에 해당하는 위치를
선택하고 두 Edge 사이의 거리를 Pixel 단위로 계산하였다.

기본 관계는 다음과 같다.

외경(pixel) = 하단 Edge 위치 - 상단 Edge 위치

이 Pixel 측정값은 이후 정밀측정 및 Calibration 단계에서
실제 mm 단위의 외경값으로 변환하기 위한 기초값으로 사용된다.

---

## 5. 측정 과정에서 확인된 문제

프로젝트 데이터에 OpenCV 기반 Edge 측정을 적용하는 과정에서
모든 영상에서 동일하게 안정적인 외곽 Edge가 검출되지는 않았다.

주요 영향요인으로 검토한 항목은 다음과 같다.

- 금속 표면의 반사광
- 샤프트 표면의 가공무늬
- 배경과 제품 경계의 명암 차이
- 실제 외곽선 이외의 내부 Edge 검출
- 촬영조건에 따른 Edge 위치 변화

따라서 단순한 Edge 검출만으로 실제 샤프트 외곽을
항상 안정적으로 선택하기 어렵다는 문제가 확인되었다.

---

## 6. 측정방법 개선 방향

기본 OpenCV 측정 결과를 바탕으로 이후 단계에서는
다음과 같은 방법을 순차적으로 검토하였다.

1. 측정영역(ROI) 제한
2. 실제 외곽 Edge 선택
3. 여러 위치에서 외경 측정
4. 이상값(Outlier) 영향 감소
5. Median 기반 대표값 산출
6. Line Fitting을 이용한 Edge 안정화
7. Sub-pixel 기반 Edge 위치 정밀화

이러한 개선 과정은 `05_Precision_Measurement`에서
별도로 정리한다.

---

## 7. 본 단계의 결론

OpenCV를 이용하여 샤프트 영상에서
ROI → Edge 검출 → 상·하 Edge 선택 → Pixel 외경 계산으로
이어지는 기본 측정 구조를 구현하였다.

동시에 제한된 프로젝트 데이터에서는
반사광, 가공무늬 및 촬영조건 등에 의해
실제 외곽 Edge 선택이 측정 안정성에 중요한 영향을 줄 수 있음을
확인하였다.

이에 따라 이후 단계에서는 ROI 탐지를 위한 YOLO 적용과
OpenCV 기반 정밀 Edge 측정 방법을 결합하는 방향으로
측정시스템을 발전시켰다.

---

## 8. 해석 시 주의사항

본 단계는 제한된 영상 데이터를 이용한 개발단계 실험이다.

따라서 본 결과만으로 실제 생산환경에서의 측정 정확도,
반복성 또는 양산 적용성을 검증하였다고 판단해서는 안 된다.

실제 적용을 위해서는 다양한 제품 위치와 촬영조건에서 확보한
독립 데이터를 이용한 추가 검증이 필요하다.
