# 03. OpenCV 기반 샤프트 외경 측정

## 1. 목적

본 단계에서는 샤프트 영상에서 외경을 측정하기 위한 **OpenCV 기반 영상처리 방법**을 구현하고, 영상 기반 외경 측정의 가능성을 검토하였다.

YOLO 기반 ROI 자동탐지를 적용하기 전, 지정된 측정영역(ROI)에서 샤프트의 상·하 외곽 Edge를 검출하고 두 Edge 사이의 Pixel 거리를 계산하는 기본 측정 구조를 구성하였다.

이 단계의 핵심 목적은 최종 mm 단위의 치수값을 바로 산출하는 것이 아니라, **영상에서 실제 샤프트 외곽 위치를 안정적으로 검출할 수 있는지 확인하는 것**이다.

---

## 2. 기본 측정 원리

OpenCV 기반 외경 측정의 기본 처리 흐름은 다음과 같다.

```text
이미지 입력
    ↓
ROI 설정
    ↓
Grayscale 변환
    ↓
영상 전처리
    ↓
Edge 검출
    ↓
상단 Edge 탐색
    ↓
하단 Edge 탐색
    ↓
상·하 Edge 간 Pixel 거리 계산
    ↓
샤프트 외경 Pixel 값 산출
```

측정된 Pixel 값은 이후 Calibration 단계에서 실제 mm 단위의 외경으로 변환하는 데 사용한다.

---

## 3. ROI 설정

전체 영상에는 샤프트 외에도 배경, 척, 설비 및 기타 구조물이 포함될 수 있으므로 외경 측정에 필요한 영역을 ROI로 제한하였다.

초기 단계에서는 ROI 좌표를 직접 지정하여 측정영역을 설정하였다.

이후 프로젝트에서는 YOLO를 이용하여 측정부 ROI를 자동 검출하는 방식으로 확장하였다.

관련 내용은 다음 폴더에서 관리한다.

```text
04_YOLO_ROI
```

---

## 4. 영상 전처리

Edge 검출 전에 다음과 같은 기본 영상처리를 적용하였다.

- Grayscale 변환
- 밝기 및 대비 확인
- 노이즈 완화
- 필요 시 Blur 적용
- Edge 검출에 적합한 영상 형태로 변환

영상 전처리는 금속 표면의 반사, 배경 변화 및 촬영 노이즈가 Edge 검출에 미치는 영향을 줄이기 위한 단계이다.

---

## 5. 상·하 Edge 검출

샤프트의 외경은 영상에서 상단 외곽 Edge와 하단 외곽 Edge 사이의 거리로 표현할 수 있다.

기본 측정식은 다음과 같다.

```text
외경 Pixel = 하단 Edge 위치 - 상단 Edge 위치
```

초기 단계에서는 정수 Pixel 위치를 기반으로 외경을 계산하였다.

---

## 6. 초기 OpenCV 측정에서 확인된 문제

기본 OpenCV Edge 측정 과정에서 다음과 같은 문제가 확인되었다.

- 금속 표면 반사에 의해 실제 외곽이 아닌 내부 Edge가 검출되는 경우
- 조명 및 배경 변화에 따른 Edge 위치 변화
- ROI 위치에 따른 측정값 변동
- 단일 또는 소수 위치 측정 시 국부 노이즈 영향이 커지는 문제
- 표면 상태에 따른 Edge 강도 변화
- 스마트폰 촬영조건 및 배율 변화에 따른 Pixel 값 변화

따라서 단순 Edge 검출만으로는 ±10 µm 수준의 정밀 측정 안정성을 확보하기 어렵다고 판단하였다.

---

## 7. 정밀 측정 방식으로의 개선

초기 OpenCV 측정 결과를 기반으로 이후 측정 알고리즘을 단계적으로 개선하였다.

주요 개선 내용은 다음과 같다.

- 단일 위치 측정 → **31-point 다점 측정**
- 단순 평균 → **Median 기반 대표값**
- 이상값 포함 → **MAD 기반 이상값 제거**
- Integer Pixel → **Sub-pixel Edge 측정**
- 개별 Edge 선택 → **Line fitting 적용**
- Edge 불연속 문제 → **Continuity 기반 추적**
- 반사에 의한 내부 Edge 선택 → **Reflection 대응 로직**
- 측정 신뢰성이 낮은 경우 → **이상 Edge 선별 및 보류**

측정엔진은 개발 과정에서 V1 → V2 → V3 형태로 개선되었다.

상세 내용은 다음 폴더에서 관리한다.

```text
05_Precision_Measurement
```

## 8. OpenCV와 YOLO의 역할 구분

```text
원본 이미지
    ↓
YOLO
측정부 위치 탐색
    ↓
ROI
    ↓
OpenCV
정밀 Edge 검출
    ↓
외경 Pixel 측정
```

### YOLO

- 측정 대상 위치 탐색
- ROI 자동 검출
- 외경 치수를 직접 측정하지 않음

### OpenCV

- 상단·하단 Edge 검출
- Sub-pixel 위치 계산
- 31-point 외경 측정
- 대표 Pixel 값 산출

따라서 YOLO는 **위치 탐색**, OpenCV는 **정밀 치수 측정** 역할을 담당한다.

---

## 9. Calibration 단계와의 연결

OpenCV에서 산출한 외경 값은 Pixel 단위이다.

최종 외경을 mm 단위로 계산하기 위해서는 기준 시편을 이용한 Pixel-to-mm Calibration이 필요하다.

```text
OpenCV 외경 Pixel
        ↓
Calibration
        ↓
외경 mm
        ↓
도면 허용범위 비교
        ↓
OK / NG 판정
```

Calibration 및 Validation 내용은 다음 폴더에서 관리한다.

```text
06_Calibration
```

## 10. 본 단계의 성과

초기 OpenCV 측정 단계에서 다음 기능을 구현하였다.

1. 샤프트 측정부 ROI 설정
2. Grayscale 및 영상 전처리
3. 상단·하단 Edge 검출
4. Edge 간 Pixel 거리 계산
5. 외경 Pixel 산출
6. 측정결과 시각화

본 단계는 전체 프로젝트의 **기본 측정 엔진을 구성한 초기 개발 단계**이며, 이후 정밀 측정 및 Calibration 단계의 기반으로 사용하였다.
